## Library documentation

- Query Context7 whenever the question touches a library, framework, SDK, API,
  CLI tool, or cloud service — including well-known ones, and including when
  you think you already know the answer. Training data goes stale; the docs
  don't. Prefer it over web search for library docs.
- Skip it for: refactoring, scripts written from scratch, business-logic
  debugging, code review, general programming concepts.

The two tools carry their own usage contract — resolution order, selection
criteria, one concept per query. Read their descriptions, don't restate them here.
